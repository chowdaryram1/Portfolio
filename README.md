# Rammohan Sandireddy — Portfolio

Professional frontend developer portfolio built with React, Vite, and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy (GitHub Pages)

1. Create a public repo named `portfolio` under `chowdaryram1`
2. Push this project
3. Enable GitHub Pages from the `gh-pages` branch (or use the Actions workflow)

Live site will be: `https://chowdaryram1.github.io/portfolio/`
